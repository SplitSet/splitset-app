🛠️ How It Works

1. Bundle Detection:
   - Checks product.metafields.bundle_app.is_bundle
   - Loads component_products from metafields
   
2. Component Display:
   - Renders inline with FastBundle styling
   - No separate container or borders
   - Clean, integrated appearance
   
3. Cart Override:
   - Intercepts form submit event
   - Prevents default behavior
   - Adds all components via /cart/add.js API
   
4. Variant Sync:
   - First component selector controls all
   - Other selectors hidden but synchronized
   - Ensures matching variants across bundle

🚨 Troubleshooting

If components are not showing:

  • Check browser console for JavaScript errors
  • Verify product has metafield: bundle_app.is_bundle = 'true'
  • Ensure theme snippet is installed: snippets/bundle-display.liquid
  • Confirm product template includes: {% include 'bundle-display' %}

To verify installation:

curl http://localhost:5000/api/theme/check-installation
