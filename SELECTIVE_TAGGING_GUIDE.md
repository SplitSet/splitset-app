# 🎯 SplitSet Selective Tagging System

This document explains how SplitSet ensures **bulletproof tagging** only for products created by the app, while leaving all other store products completely untouched.

## 🔒 **Safety-First Approach**

### **What Gets Tagged**
✅ **Products created by SplitSet ONLY**:
- Original products processed through SplitSet
- Component products generated by splitting
- Bundle products created by the app
- Variant products created through the app

### **What NEVER Gets Tagged**
❌ **Regular store products**:
- Products uploaded directly to Shopify
- Products from other apps
- Imported products from CSV/feeds
- Manually created products
- Third-party app products

## 🔍 **How We Identify SplitSet Products**

### **Detection Criteria (Multiple Checks)**

#### **1. App-Specific Tags**
```javascript
// Products created by SplitSet have these markers
tags.includes('splitset-created') ||
tags.includes('auto-generated') ||
tags.includes('set-component') ||
tags.includes('auto-bundle')
```

#### **2. App Metafields**
```javascript
// Our app adds metafields to products it creates
metafields.namespace === 'bundle_app' ||
metafields.namespace === 'splitset' ||
metafields.key === 'splitset_created'
```

#### **3. Product Title Patterns (Secondary Check)**
```javascript
// Only if combined with app tags
title.includes('component') ||
title.includes('- bundle') ||
title.includes('top') ||
title.includes('bottom') ||
title.includes('dupatta')
```

## 📋 **Tagging Workflow**

### **When Products Are Created**
1. **User runs SplitSet** on original product
2. **Original product** → Gets tracking tags + set-specific tags
3. **Component products** → Gets tracking tags + component-specific tags
4. **All products** → Get metafields with our app namespace
5. **Orders containing these products** → Automatically tracked for ₹9 billing

### **When Orders Are Placed**
1. **Check order tags** for tracking markers
2. **Check line item properties** for SplitSet markers
3. **Verify product tags** (if needed) for SplitSet origin
4. **Count for billing** only if verification passes

### **When Maintenance Runs**
1. **Scan all products** in store
2. **Filter to SplitSet-created only** using detection criteria
3. **Check tracking tags** on filtered products
4. **Fix missing tags** only on SplitSet products
5. **Leave all other products** completely untouched
